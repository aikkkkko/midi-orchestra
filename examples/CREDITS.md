# Example credits

## Music

Original phrases written for this project and generated by `scripts/generate_examples.py` with the Python standard library: D major, 88 BPM, 4/4, every note on a 480 PPQ beat grid. The files contain tempo, time signature, program, sustain pedal and note events; track names only name the part. No user project, account information or other MIDI text is included.

- Solo files (`piano.mid`, `violin.mid`, `surge_*.mid`): five bars over Gmaj9 | A6 | F#m7 Bm7 | Em9 A7sus4 A7 | Dmaj9, one phrase written for each sound.
- `ensemble.mid`: eight bars in seven tracks. Piano theme over Gmaj9 | A6 | F#m7 | Bm7; the violin restates its opening motif in rising sequence over Em9 | F#7 | Gmaj7 A7sus4 A7 | Dmaj9 with a cello countermelody. Track indices for `--track`: 0 piano, 1 violin, 2 cello, 3 surge_pad, 4 surge_bass, 5 surge_pluck, 6 surge_texture.

## Sounds

- Surge XT 1.3.4 factory presets, factory metadata credit: Claes. `surge_pad`: Pads/MKS-70 Warm Pad.fxp (historical internal meta.name: Buggy Brass); `surge_bass`: Basses/Mellow.fxp; `surge_pluck`: Plucks/Clean.fxp; `surge_texture`: FX/Space Adventure 1.fxp. Official source: https://github.com/surge-synthesizer/releases-xt/releases/tag/1.3.4 . Rendered with DawDreamer 0.9.0.
- Piano: FreePats YDP Grand Piano 2016-08-04. Credit: FreePats / Roberto; Yamaha Disklavier Pro samples recorded by Zenph Studios / Dr. Mikhail Krishtal for OLPC. License: CC BY 3.0 https://creativecommons.org/licenses/by/3.0/ . Source: https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html . Rendered with FluidSynth 2.6.1 and its built-in reverb.
- Violin and cello: MIDI-DDSP 0.2.6 / DDSP 3.2.0, official URMP pretrained model. Source: https://github.com/magenta/midi-ddsp . The 16 kHz output is resampled to 48 kHz; resampling adds no source bandwidth. The model samples its expression, so every render differs; each string part used the best of several takes by measured intonation against the MIDI.

## Reproduce

```bash
python scripts/generate_examples.py
for id in surge_pad surge_bass surge_pluck surge_texture piano violin; do
  midi-orchestra render $id --midi examples/midi/$id.mid --normalize --out stems/$id
done
i=0
for id in piano violin cello surge_pad surge_bass surge_pluck surge_texture; do
  midi-orchestra render $id --midi examples/midi/ensemble.mid --track $i --normalize --out stems/ensemble_$id
  i=$((i+1))
done
python scripts/mix_examples.py stems
```

`mix_examples.py` (requires numpy) sets each stem by BS.1770 loudness, then applies high-pass filtering, panning, a shared synthetic room reverb, a -1 dBFS peak limiter and a final fade. Solo examples are mixed to -18 LUFS and the ensemble to -16 LUFS. In the ensemble the violin is the reference level, with piano -1.5 LU, cello -5, bass -6, pad -9.5, pluck -11 and texture -15. MIDI-DDSP synthesizes low noise during long rests, so the ensemble string stems are gated to start at their entry in bar 5. Every WAV is 48 kHz stereo 24-bit PCM with only format and sample data chunks.

Changes to the source sounds: MIDI performance, filtering, level, panning, added reverb, mixing, limiting and fade. Retain the above credits when sharing the audio examples.
