# 发布与隐私

[English](en/releasing.md) · **简体中文**

v0.1.0 发布目录按白名单重新组装，内容来自明确列出的源码文件。代码和文档中的路径都是参数或通用模板，具体主机配置保存在 `*.local.json`。

发布包包含源码、配置模板、文档、技能、测试和示例媒体。凭证、SSH 配置与密钥、主机指纹文件、含本机用户名的路径、历史归档、原始部署配置、安装好的环境、插件与模型大文件、远端任务和日志都留在发布包之外。WAV 只保留 PCM 格式和采样数据；MIDI 由标准库重新生成，只含演奏事件和声部名。

```bash
python scripts/audit_release.py .
python scripts/build_release.py --out ../release-artifacts
```

构建器打包预先列出的文件，审计通过后生成 ZIP、tar.gz 及其 SHA-256。压缩包使用相对路径和固定时间戳，文件所有者、扩展属性和 Git 历史都留在压缩包之外。`MANIFEST.sha256` 用来核对包内文件，压缩包本身的校验值在外部的 `SHA256SUMS.txt`。

审计器检查密钥格式、常见令牌、个人目录、主机名格式、私网地址、排除文件和符号链接。报告中只出现类别和相对文件名，疑似凭证的具体值留在原处。模式扫描覆盖常见形式，与白名单组装和人工检查配合使用。

Wheel 只包含命令行工具；完整源码 ZIP/tar 包含技能、安装脚本、文档、测试和试听，用它来创建 GitHub 仓库。上传仓库时使用发布目录中的内容，工作目录、安装目录和 `config.local.json` 留在本机。
