# Agent 技能

[English](en/agent-skill.md) · **简体中文**

仓库附带 `.agents/skills/render-midi/SKILL.md`。技能负责按需求作曲、挑选音色、考虑各引擎的特点、调用同一个命令行工具并交付文件；合成实现全部在命令行工具中。

在能发现该目录的 agent 工作区中使用，或按所用 agent 的方式安装整个技能目录。用户级安装时请保留 `references` 目录，里面有音色选择和作曲指南。使用前先安装 `midi-orchestra` 并准备好私有配置。

示例请求：

- “用 render-midi 写一段 20 秒的轻快转场音乐，拨奏加合成低音，输出 WAV 和来源说明。”
- “用 render-midi 把这段 MIDI 做成柔和铺底，输出可试听的 WAV 和来源说明。”

agent 会按曲风、时长、速度和调性写出多轨 MIDI，把生成脚本和 MIDI 一起保存，方便之后修改；再逐轨渲染并交回音频。技能可以被正常发现和隐式调用，无需 MCP 服务，也不含任何账户凭证。听感由你来确认，agent 会说明哪些结论来自测量、哪些音色已经试听过。
