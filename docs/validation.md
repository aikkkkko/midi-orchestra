## macOS 15（Apple 芯片）

- 安装脚本从官方 dmg（SHA-256 已固定）取出 Surge XT VST3 和原厂音色，在 dmg 已下载的情况下 12 秒完成；复制后的插件签名校验通过，`doctor` 全部通过，重复运行会先备份原配置。
- 四种 Surge 音色在本机渲染：长度与 Windows 完全一致，各频段能量差在 0.2dB 以内，包络相关系数 0.87–0.98（纹理音色带随机调制）。macOS 原厂文件生成的四个预设与 Windows 的 SHA-256 完全相同。
- Homebrew 的 FluidSynth 2.6.1 渲染钢琴，与 Windows 的结果逐采样相关系数为 1.0000。

## 本轮修复

- Surge 在第一个音频块才应用载入的预设，旧 worker 因此丢失 t=0 处的音符（原版铺底示例重新渲染时第一个和弦整段缺失，首个声音出现在 3.0 秒）。worker 现在载入预设后先渲染 0.1 秒预热，同一探测 MIDI 的首个声音从 4.09 秒提前到 0.00 秒。
- 本机模式以前会解析解释器路径中的符号链接，macOS 虚拟环境的 python 因此找不到依赖（Windows 的虚拟环境使用文件副本，所以之前一直正常）。现在保留符号链接。

这类问题需要逐项检查才能发现，所以本轮另做了以下检查：

- 和声：按和弦表逐段统计成品频谱能量，钢琴、小提琴、铺底和拨奏有 83–100% 落在和弦音上，其余是有意安排的经过音和色彩音。
- MIDI-DDSP 音准：逐音估计基频并与 MIDI 比较（估计器在合成音上误差 ±2 音分）。小提琴和大提琴各渲染 3–4 遍，选音准最好的一遍；大提琴模型每遍都偏高约 12 音分，混音时校正，校正后平均 -1 音分，起音位移 7ms。
- MIDI-DDSP 在休止和末音之后会输出 -19 至 -35dBFS 的噪声，混音只在声部有音符的范围内打开该声部。
- 响度：独立试听 -18 LUFS，组合试听 -16 LUFS，峰值最高 -1dBFS；本工具的 BS.1770 计算与 pyloudnorm 相差小于 0.1LU。
